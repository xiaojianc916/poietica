# 评审清单

评审 / 自检时按序过。任何一条不过，改动就不算完成。

## 归属与分层

- [ ] 每类状态只有一个所有者、一条写入路径；没有影子状态与兜底副本。
- [ ] 依赖方向只向下，同层无边；跨包只走公开 exports。
- [ ] 领域层零 IO：不出现数据库、协议、窗口、界面的知识。
- [ ] 只有白名单包碰 `@tauri-apps/*`；host-agnostic crate 不知道自己跑在 Tauri 里。
- [ ] 组合根里只剩：解参、调 crate、DTO 互转、emit、宿主节拍。不需要 `AppHandle`/`State`/`Emitter` 就能写出的逻辑已住进 crate 并有单测。
- [ ] 通用层没有 `if agent_id == "某家"`；厂商名只在档案文件里。

## 文件与命名

- [ ] 目录名说能力，没有桶名与 `-Impl` 式技术后缀。
- [ ] 没有 `legacy`/`v2`/`new`/`old`/`*2`；没有旧名转发层。
- [ ] 拆/合满足 `PLACEMENT.md` 的判据；超 800 行不拆的，模块头写明了内聚理由。
- [ ] 常量只有一处产地；被迫复制处注明了正本当前路径。
- [ ] 生成物没被手改；协议类型来自快照而非手抄。

## 不变量

- [ ] 顺序正确：写字节先于写账、删账先于删字节；中间态是可被自动回收的那一种。
- [ ] 取消是状态迁移，不是错误；取消、超时、异常模型输出、过期结果都验过。
- [ ] 单一分发点：没有第二个 match 主干在别处重复判别同一种帧。
- [ ] TS store：不可变快照 + 单一 commit 写点 + 引用不变不通知 + 派生视图记忆化。
- [ ] 时钟、序号、路径单点发放。
- [ ] `Debug` 不打载荷；密钥不落盘、不进日志。

## 注释与文档

- [ ] 注释只讲"当前为什么"，凝练；无纯历史叙述。
- [ ] 注释里的路径锚点都是当前路径；外部断言有来源与日期。
- [ ] 触及 AI 上下文、持久化、IPC、权限或公开 API → 记了 ADR（一号一文件，被取代则标 superseded）。
- [ ] 文档没重抄代码里的表；只留指针。

## 验收命令

```bash
bun run check          # biome + 架构 + typecheck + test + rustfmt + clippy + cargo test + IPC 绑定一致性
bun run ipc:check      # 涉 IPC 时
bun run kap:spec:check # 涉协议快照时
```

涉 AI 的改动另验：取消、超时、异常模型输出、过期结果、密钥不泄漏。测试内的 `expect`/`unwrap` 必须在测试作用域逐处写明带理由的 allow。
