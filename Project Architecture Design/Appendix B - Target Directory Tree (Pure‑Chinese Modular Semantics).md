# 附录 B · 目标目录树（纯中文模块化语义）

<aside>
🧭

本树是附录 A 的**语义镶像**，用于审阅与沟通，**不作为磁盘目录名**（代码仓库一律用英文模块名）。每个模块名后的【】就是它的四问四答摘要：我是什么、我拥有什么、谁可调用我、我不许知道什么。

</aside>

## B.1 总览：五层一向

```
【语义层级】
第五层·组合根（只接线，不裁决）
   ↑ 只能往下依赖
第四层·界面表现（只渲染，不持真相）
   ↑
第三层·边界适配（与外部世界打交道的唯一居所）
   ↑
第二层·领域内核（定义这个产品是什么，零 IO）
   ↑
第一层·公共词汇（错误、时钟、生成契约）
```

## B.4 一句话自检

数据从**智能体协议适配**进来 → 经**会话领域**裁决 → 写进**事件账本（唯一真相）** → 提交后才投影为快照 → 由**界面表现**只读渲染；反向只有三条命令，且均为“先落账、再执行”。每个模块名后都挂着四问四答；答不上来的模块不得建立。
