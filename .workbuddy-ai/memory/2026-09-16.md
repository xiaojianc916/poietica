# 2026-09-16

## 连不上 agent 的提示从工具栏搬到输入框上沿

用户要求：'没连上 agent，点击重试' 不要再以裸文字出现在输入框工具栏里（那里是模型选择器
的位置），改成输入框卡上沿的一条提示条（参考稿：红图标 + 一句话 + 重试图标按钮）。叉叉
按钮明确不要（收起它等于收起重试入口）。点重试图标要转圈表示正在重连。

改动：

- 新增 `packages/conversation/src/surface/composer/composer-notice.tsx` + `.css`：
  `ComposerNotice`，卡外与卡同宽、高 `--cp-row`(36px)、圆角 `--cp-radius-item`；
  红标记用 `--ui-destructive`，旋转复用 assistant.css 的 `assistant-spin`。
- `assistant-surface.tsx`：dock 里 `PromptQueue` 之后渲染这条提示，`DISCONNECTED`
  常量（'没连上 agent，点击重试'）在此定义，原始失败原因只做整条的 `title`。
- `session-controls.tsx` / `.css`：删掉 `UNAVAILABLE` 常量与 data-empty/data-failed
  那条失败分支（SessionControls 现在只在没控件时返回 null）。
- `assistant-composer.tsx`：`controlsFailure` / `onRetryControls` 两个 prop 一并删除。
- 旋转要有真实时长，所以重试改成交回这一趟的承诺：
  `SessionControlsStore.retrySelectors` 不再乐观清掉失败、返回 `#reopen` 的 promise；
  `AgentCapabilityStore.refresh` 返回 `#load` 的 promise；`AgentControlsView.retry`
  与 `AssistantSurfaceProps.onRetryControls` 类型随之变成 `() => Promise<void>`。
  副作用（有意）：点了重试之后提示条会一直留到这一趟落地，不再闪一下。

验证：biome 干净；conversation typecheck + 193 测试通过；desktop typecheck + 45 测试通过；
automation typecheck 通过；`tools/architecture/verify.ts` 只剩工作区里既有的 2 条
workbench 违规（skill-document-pane / auxiliary-dock，与本次无关）。

未做（可续）：`assistant-surface.tsx` 里转录失败那句仍是裸 `<p role="alert">`，
也可以收敛到同一条提示上。
