# 会话执行所有权

选择独立会话用例包，而不是在命令目录中增加转发服务或通用事件总线。
寻址、投递、帧持久化和处置都由同一用例边界执行；平台类型只出现在宿主。

## 不变量

- 同一对话的创建/恢复串行；数据库拒绝覆盖已有会话身份及零行绑定。
- 失败补偿只针对本次刚创建、未绑定成功的会话。
- 附件先落字节再落引用；等长不能证明字节正确。
- 文件发布使用 tempfile；读取校验摘要，不在发送时省略坏附件。
- 本机帧先提交后发布；flush 不得把已知持久化失败洗成成功。
- 创建工人的所有者负责最终关闭；关闭后已有 sink 也不能再接受帧。
- 远端处置未确认成功时保留意图，不把超时当成完成。

## 验证

用例和资产测试不需要 WebView；现有全仓检查继续约束调用点和生成契约。
自动化原生执行、全部跨进程取消、崩溃后的创建补偿和跨平台交互尚未据此验收。
