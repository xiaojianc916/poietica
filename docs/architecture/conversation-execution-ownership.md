# 会话执行所有权

桌面命令转换 IPC 值并提供平台资源；自动化提供执行意图。两者只调用会话运行时公开用例，不持有连接句柄或会话解析器。

## 单向依赖与事实归属

- 桌面组合根注入进程准备、资产交付、事件发布。
- 自动化运行时拥有调度、目录命令和执行核对；会话运行时不依赖自动化运行时。
- 会话运行时拥有身份解析、提交、控制、配置、分叉、删除、导出和持久化恢复。
- 私有连接所有者拥有启动门、连接、工作线程与取消域；它通过具体回调交付事件和就绪通知，不读取账本。
- 断开在阻塞任务中先排空连接工作线程，再刷新日志；关闭在排空后关闭日志。
- SQLite 拥有身份绑定、准入、处置意图；绑定不能替换已有身份。
- KAP 拥有执行和 transcript；渲染层只投影官方数据，不以本地推断替代终态。

## 不变量

- 创建、恢复、分叉经过同一解析器；要求已有会话时不得创建替代品。
- 取消和核对只读绑定，不等待提交租约，不创建会话。
- 提交租约覆盖配置、准入、回执；工具快照租约覆盖远端读取。
- 本地删除与远端归档意图同事务提交，确认远端成功才销账。
- 分叉绑定失败后，经 writer 屏障确认未绑定才补偿本次创建的分叉。
- 导出对话框不持有租约，选完路径后重新核对来源。
- 清理失败记录诊断，不把已提交删除声称为回滚。
- 错误经统一会话命令错误进入宿主 Problem，契约由既有生成器更新。

## 验证边界

数据库测试覆盖处置回滚和分叉补偿；运行时测试覆盖只读寻址及无绑定入口；Rust 隐私与编译失败 doctest 守住公开边界。

这些测试不证明远端创建的崩溃原子性、所有跨进程取消、完整后台任务回收和全部平台退出行为；这些能力仍需独立集成验收。
