# 表格列类型的归属与落盘

## Decision

表格列有 13 种类型（文本/数字/货币/单选/多选/日期/人员/复选框/链接/邮箱/电话/图片/附件），词汇由 Rust 的 `SheetFieldKind` 定义，经 specta 生成到 TS，TS 不手抄。

CSV 保持纯 RFC 4180（Excel 能直接打开）：类型不住进 CSV，住在同目录的边车文件 `<表名>.schema.json`，内容是按列对齐的 `kind | null` 数组。`TableSheet` 经 IPC 携带 `kinds`，`null` 表示未指定、走原有的值推断（老文件、无边车文件、外部改过表头的列全部落在这里）。

版本号指纹叠加边车字节，只改类型也算改动；重命名连边车一起搬家；删除先清边车再进回收站；导入的 CSV 不带边车；新建表格种子自带 `[text, number, select, date]`。目录与搜索无视边车文件。边车损坏按无类型打开，不为此打不开表。类型只影响展示、排序与筛选语义，不改写单元格的值。

## Consequences

CSV 仍是用户数据的唯一真相，边车只是展示注解：删掉边车最多丢列类型，不丢数据。新增第 14 种类型时 Rust 加 variant 即可，老版本读到未知名字按未指定处理。
