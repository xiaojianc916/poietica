# 0018. 对话索引不加密

- Status: accepted
- Date: 2026-08-07
## Context

`threads.sqlite3` 里只有一张表，七列元数据：对话 id、标题、属于哪个 agent、
握着哪个会话号、建立与更新时刻、附件链接。对话正文一个字都不在其中 —— 它躺在
agent 自己的存储里，明文。

## Decision

这个库不加密。

## Consequences

加密它保护不了任何东西：想读对话的人不需要撬这个库，直接读 agent 那份明文更快。
换来的是一条要在三个平台上正确管理的密钥链、一个必须与库同寿的钥匙串条目、
以及一份没有它就再也打不开的用户数据。

API 密钥同理不在这里 —— 它们由 agent 自己的 CLI 写进它自己的 config.toml。
这个应用一份密钥副本都不存。

需要保护对话内容时，答案是整盘加密（BitLocker、FileVault），不是给一张元数据表
套一层壳。
