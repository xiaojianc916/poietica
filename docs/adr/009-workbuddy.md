# ADR-009：WorkBuddy 去留

状态：暂缓（用户决定，2026-11-08）。本轮重构不动 WorkBuddy 反代功能。

背景：审查报告把 WorkBuddy 内置反代列为产品地基风险（D9）：对没有公开 API 的第三方服务做协议逆向、多账号轮换与签到，并且运行在 Core 进程里。报告给出的选项是「移出默认发行版，或按 ADR-009 处理」。

决策：

- 本轮重构明确保持 WorkBuddy 现有行为、装配、契约与默认值不变。
- 不把 WorkBuddy 移出默认发行版，不改变它的开关默认值，不把它的存储迁入凭据库。
- 该功能的架构风险仍然成立：它位于 Core 的故障域内，凭据由引擎自己的数据目录保存，协议可能随上游改动失效。风险登记在待决清单，等用户单独裁决后再动。

后果：

- P0 的「WorkBuddy 去留」以「暂缓」关闭，但不声称风险已消除。
- 后续阶段不得顺带修改 WorkBuddy；任何改动必须先有独立的决定与验收范围。
