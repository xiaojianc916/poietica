# 会话命令的完整用例边界

状态：接受。

人工提交与自动化共享连接运行时的提交入口。一次命令持有同一会话租约，依次完成
平台资产交付、配置、准入、投递与收据处理。平台资产通过显式闭包传入；运行时不认识 Tauri。
配置公告使用改写返回的完整选择器表，目标状态仍由 agent 读取，公告失败不伪装成改写失败。

本地索引拥有标题、置顶、归档与用量记录。目录用例在账本的 writer lane 判定行是否存在；
宿主只在这些入口转换生成的 DTO。未改变数据库布局、自动化身份或不安全重放的判据。

准入、网关与恢复是运行时内部步骤，不作为外部提交入口。内部测试随实现归属移动，
公开用例保留无 WebView 的入口验证。TypeScript 依赖边界同时检查编译器解析出的目标文件；
别名不豁免层次、依赖声明、公开 exports 或类型契约规则。
