## 3. 每个工具详解

### 3.1 Files & search

**read**（`tools/read.ts`）
- 参数：`path`（必需；本地路径、内部 URI 或 URL，支持行内 selector）。
- URI schemes（`#handleInternalUrl` + `internal-urls/`）：`agent://`（含 `?q=`）、`artifact://`、`memory://`、`skill://`、`rule://`、`local://`、`mcp://`、`history://`、`proc://`、`omp://`、`vault://`、`security://`、pr/issue 协议、`ssh://`、`attachment://N`；http(s) 走 `tools/fetch.ts` 管线。
- 行内 selector（`tools/read-selector.ts`）：`:N`、`:N-M`、`:N+K`、`:N-`、`:-N`（tail）、逗号分隔多区间、`:raw`、`:img`（SVG 渲染）、复合 `:raw:50-100`、`:conflicts`（git 冲突区块）；图片/attachment/local 支持 `?q=` 视觉提问；PDF 页选择（`read-pdf.ts`）、sqlite 表:行（`read-sqlite.ts`）、归档（`read-archive.ts`）。
- approval 按参数（ssh 目标→exec；PDF 截图读取→exec）。
- 要点：投机预读（speculation assess/execute/commit/discard）；同内容重复读 3 次注入"循环破坏"提示（`REPEAT_READ_HINT_THRESHOLD=3`）；目录返回带 mtime；20MB 图片上限；`tools.outputMaxColumns` 列宽截断。

**write**（`tools/write.ts`）
- 参数：`path`（必需）、`content?`。
- approval 按路径：`xd://` 设备取该设备自身 tier（issue #7923）；`xd://resolve|reject|propose` 与 `agent://` 为 read；`proc://` 与 ssh 目标 exec；其余 `resolveFileWriteApprovalTier`。`deviceOnlyWrite` 模式拒文件系统写（仅允许 `write xd://<tool>`）。
- 要点：`concurrency="exclusive"`；`write conflict://<N>` 用记录的冲突区块拼接替换、`conflict://*` 批量解决（`conflict-detect.ts` ConflictHistory）；hashline `[path#TAG]` 头解析；写后 `bumpFileMutationVersion` + 延迟 LSP 诊断；`file-write-fallback.ts` 降级写；`edit.blockAutoGenerated` 时原生检测拒绝生成文件（lockfiles 等，`auto-generated-guard.ts`）。

**edit**（`CA/src/edit/`）—— 详见 [code-intelligence.md](./code-intelligence.md) §3（hashline 机制、五模式）。approval：全部目标路径为 read-tier 时 read，否则 write；`concurrency="exclusive"`；流式参数预览（`openArgStream` + 原生 EditStore）。

**grep**（`tools/grep.ts`）：`pattern`（必需）、`path?`、`case?`、`gitignore?`、`skip?`；native ripgrep；支持 archive/sqlite/omp:// 虚拟范围；`totalMatchLimit` 选项；`XDEV_KEEP_TOP_LEVEL` 保 top-level。

**glob**（`tools/glob.ts`）：`path?`、`hidden?`、`gitignore?`、`limit?`；native glob + 超时。

**find（jfind）**（`tools/jfind/`）：语义 grep——`query`（必需）、`grep_keywords[]`（必需）、`path?`（支持 `omp://` 文档范围）；judge 模型级联（`jfind/cascade.ts`：词法先验/文件名排序/verifier）；返回 hits（相对路径、contentScore、行区间+snippet），无命中标 `useless`；尾行统计 tokens/成本/耗时。

### 3.2 Runtime

**bash**（`tools/bash.ts`）
- 参数（4 个 union 变体）：`command`（必需）、`timeout?`（秒；0=无 deadline；clamp 1–3600，`TOOL_TIMEOUTS.bash` 默认 300s；`tools.maxTimeout` 再封顶）、`cwd?`（支持 skill:// 等 URI 展开）、`pty?`、`async?`（后台作业；需 `async.enabled`，注册进 AsyncJobManager）、`name?`(≤48 字符) + `ready? {log?, port?, host?, timeout?}` + `env?` → **service 模式**（经 `launch/services.ts` 启动受管守护进程等待就绪；需 `launch.enabled`）。
- 自动后台：`bash.autoBackground*` 超阈值前台命令转后台 job（18.3.0 起 `strategy` 默认 `catalog`）。
- approval 按命令：`CRITICAL_BASH_PATTERNS`（`rm -rf /`、`sudo rm`、`chmod -R … /`、`--no-preserve-root` 等）→ exec+override；`bash.patterns` 规则 allow/deny/prompt（复合命令按 segment 匹配，`bash.allowCompoundCommands`）；否则 exec tier。
- 要点：in-process coreutils（pi-natives pi-shell/uutils；`PI_DISABLE_UUTILS_BUILTINS` 关闭）；行首 `cd <path> && …` 提取为结构化 cwd；`bashInterceptor.enabled` 默认 10 条规则把 cat/grep/find/sed -i/perl -i/awk -i/重定向/nohup/长驻服务/watch 重定向到专用工具；`worktree.clone` 时改写 `git worktree add`；内部 URL 先展开；变更型 gh 子命令失效 github-cache；流式输出 OutputSink head/tail 中段省略。

**eval**（`tools/eval.ts`）：持久内核 Python(py)/JavaScript(js)。
- 参数：`language`（按会话启用后端动态收窄）、`code`（必需；顶层 await；`%` 命令）、`title?`、`timeout?`（默认 30s，0=不限，clamp 1–3600）、`reset?`（仅重置该内核）。
- approval exec；`eval.py/js` 门控（env `PI_PY`/`PI_JS`）；Python 走 `checkPythonKernelAvailability` 预检。
- 扩展面：browser/computer 以 prelude 对象注入 JS/Python 环境；eval 能经 bridge 回调已授权工具（`getToolForEvalBridge`）。

**debug**（`tools/debug.ts`）：28 action —— 详见 code-intelligence.md §2。adapter：gdb、lldb-dap、codelldb、debugpy、dlv、rdbg 或 dap.json 条目；只读 action read 级，其余 exec。

### 3.4 Coordination

**task**（`CA/src/task/`）—— 详见 [subsystems.md](./subsystems.md) §4。参数（4 变体：单发/批量 × isolation）：`name?`、`agent='task'`、`task`（必需）、`outputSchema?`、`schemaMode permissive|strict`、`tools?`、`isolated?`、`effort lo|med|hi`；批量 `context` + `tasks[]`；`"+": "delete"` 拒绝未知键；`strict=false`、`lenientArgValidation=true`。

**wait**（`tools/wait.ts`）：无参数；阻塞等下一个后台结果（owned jobs）、IRC 消息或受管服务完成；有未投递 job 立即返回；无等待对象返回 `nothingToWaitForResult`；`WAIT_MAX_MS` 30 分钟；进度 onUpdate 每 500ms；`interruptible=true`（steering 打断返回 useless）。

**todo**（`tools/todo.ts`）：`op: init|start|done|rm|drop|block|unblock|append|view` + `list? [{phase, items[]}]`、`task?`、`phase?`、`items?`、`reason?`；`concurrency="exclusive"`；`lenientArgValidation=true`。

**ask**（`tools/ask.ts`）：`questions: [{id, question, header?, options: [{label, description?}], multi?, recommended?（0-based）}]`（≥1）；UI 选择器；`concurrency="exclusive"`（两个并发 ask 抢焦点）；`ask.timeout`（默认 240s，0=禁用）；narrow 校验选项标签不与保留运行时标签冲突。

## 5. 审批三层合并（`tools/approval.ts`）

1. **工具自身 decision**（静态 tier `read|write|exec` 或 `(args) => ToolApprovalDecision`；可含 `override`、`policy: allow|deny|prompt`、`policyKey`、`reason`；deny 直接拒）。
2. **用户 `tools.approval.<tool>`**（allow|deny|prompt；支持 policyKey 设备级；legacy 名字 deny/prompt fail-closed 继承）。
3. **模式 `tools.approvalMode`**：`always-ask`（全 prompt）/ `write`（read+write 放行、exec prompt）/ `yolo`（全放行）；schema 默认 yolo；`--auto-approve` 强制 yolo；缺 settings 时 **fail-closed always-ask**。
- `denyError` 区分 tool-owned 与 user 配置来源。
- 统一入口 `resolveApprovalFromContext`：ExtensionToolWrapper、`refuseByWritePolicy`、MCP approval preflight、eval prelude host calls 共用（防漂移）。ACP 宿主另有 `session/acp-permission-gate.ts`。

## 6. xd:// 设备挂载（discoverable 工具瘦身）

- `tools.xdev`（默认 true）：`loadMode: "discoverable"` 的内置与 custom/MCP 工具从请求 tools 数组卸下，改为设备——`read xd://` 列设备；`read xd://<tool>` 文档+JSON schema；`write xd://<tool>` 执行（content 为 JSON 参数，`validateToolArguments` 校验，流式 content 解码支持实时预览）。
- `XDEV_KEEP_TOP_LEVEL`（`xdev.ts` L46–54）：todo、yield、ask、grep、web_search 保持 top-level。
- 有 read 无 write 的受限会话授予 device-only write（不扩权）。

## 7. 结果截断 / artifact spill（`tools/output-meta.ts` + `tool-result.ts`）

- 所有内置工具结果经 `wrapToolWithMetaNotice`。
- spill 触发：文本总字节 > `tools.artifactSpillThreshold`（默认 50KB ≈ 12.5K tokens）→ 全量存 `artifact://N`，正文 head+tail 中段省略（`tools.artifactHeadBytes/artifactTailBytes/artifactTailLines`；headBytes=0 退化 tail-only）+ `[raw output: artifact://N]` 恢复链接；bash/eval 自带 artifact 或读 artifact:// 时跳过；写盘失败仍截断不给链接（fail-safe）。
- `useless` 标记（压缩可省略）、`isError`、`meta`（truncation/source/diagnostics）由 `toolResult()` builder 装配。
- 超时 clamp 表（`tools/tool-timeouts.ts`）：bash 300s(1–3600)、eval 30s、lsp 20s(5–300)、debug 30s(5–300)、browser 30s、computer 120s、fetch 20s(1–45)、ssh 60s；`tools.maxTimeout` 全局封顶。
- LSP 延迟诊断：edit/write 后 `queueDeferredDiagnostics` → yield 队列注入；陈旧诊断按 `bumpFileMutationVersion` 丢弃。

## 8. 并行与其它管线要点

- `AgentTool.concurrency: "shared"|"exclusive"|fn`：exclusive（write/edit/todo/ask）只串行化执行，不影响持久化顺序；同批其余并行。
- task 批量 spawn 由 `task/parallel.ts` / `workpool.ts` 管理；async spawn 注册 job 立即返回，`wait`/quiescence barrier 收敛。
- dry-run/预览：edit/ast_edit 流式预览（`openArgStream` + 原生 EditStore；stream matcher 用 `matcherDigest` 真实文件内容渲染）；ast_edit `deferrable=true` 暂存 → `write xd://resolve|reject` 定夺（createTools 强制保留 write）。
- 支撑件：`conflict-detect.ts`（git 冲突扫描/记录/拼接）、`auto-generated-guard.ts`、`fs-cache-invalidation.ts` / `gh-cache-invalidation.ts`、`bash-interceptor.ts`、`bash-worktree-rewrite.ts`、`bash-pty-selection.ts`、`output-schema-validator.ts`（yield JSON Schema 校验）、`path-utils.ts`（`confineToWorkspace` 围栏）。
