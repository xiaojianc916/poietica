# omp 安全与遥测

> 来源：`CA/src/tools/approval.ts`、`CA/src/secrets/`、`CA/src/security/`、`CA/src/telemetry-export*.ts`、`CA/src/stats/`、omp-stats 包、settings-schema（18.3.0）。

## 1. 审批模型（详见 tools.md §5）

- 三层合并：工具 decision（deny 直接拒）→ 用户 `tools.approval.<tool>`（allow/deny/prompt + policyKey 设备级）→ 模式 `tools.approvalMode = always-ask | write | yolo`。
- **fail-closed 原则**：缺 settings 时 always-ask；advisor/桥工具无 approval context 时 always-ask 空策略（不可无提示执行）。
- bash `CRITICAL_BASH_PATTERNS`（`rm -rf /`、`sudo rm`、`chmod -R … /`、`--no-preserve-root` 等）→ exec+override 强制提示。
- `event.tool_approval_requested/tool_approval_resolved` 事件可观测；扩展 `tool_call` 事件返回 `{block: true, reason}` 编程裁决；`setToolUIContext` 可注入自定义审批 UI。
- ACP 宿主 `session/acp-permission-gate.ts`；`setUsageFallbackConfirmer` 确认 usage-reserve 触发的模型降级。

## 2. 工作区围栏与隔离

- `confineToWorkspace`（tools/path-utils.ts）路径围栏。
- task.isolation 物理隔离：快照（apfs/btrfs/zfs/reflink/overlayfs/projfs/block-clone/rcopy）→ 应用回主工作区 → 销毁；基线 ≤1GiB。
- skill containRoot：Agent Plugins spec §4.1——`skill://` 资源访问必须 realpath 解析在插件根内（symlink 只可指向根内文件）。
- `restrictToolNames/allowRestrictedCustomTools` 收敛工具面；受限会话 device-only write（不扩权）。

## 3. secrets 与脱敏（详见 config-auth-secrets.md §7）

- `secrets.enabled`（默认 false）：发 provider 前混淆（HMAC keyed placeholder，key 为 `secret-placeholder.key` 0600，永不发出）+ 工具执行前 `deobfuscateToolArguments` 还原；`replace` 模式不可逆。
- env secrets 自动收集（KEY/SECRET/TOKEN/PASSWORD…命名且 ≥8 字符；URL 内嵌密码）；vendor 凭据模式库（GitHub/OpenAI/AWS/Google/Slack/npm/Stripe/HuggingFace/SendGrid/JWT/Bearer/PEM）。
- pi-ai 边界无基钥流式 redaction（`[openai_token_redacted]`）。
- `isCredential()` 设置键（`auth.broker.token`、`hindsight.apiToken` 等）永不被打印/导出。
- **share/export 脱敏**：`share.redactSecrets`（默认 true）；stream 广播 `stream.redactPatterns[]` redactor。

## 4. 模型输出防护（模型输出是不可信输入）

- `tools.abortOnFabricatedResult`：模型伪造 tool result 立即断流。
- Harmony leak 防护（GPT-5 协议泄漏：abort_retry/truncate_resume 各 ≤2 后抛错）。
- leaked-thinking healing（非官方端点流包装；严格 hostname 判定防 `api.openai.com.evil` 仿冒）。
- `features.unexpectedStopDetection`（none/mechanical/smart）。
- `edit.blockAutoGenerated` 原生检测拒绝生成文件；`edit.enforceSeenLines` 必须先 read。
- TTSR 规则系统（agent-core-sessions.md §5）作为流式输出合规护栏。

## 5. 凭据安全边界

- `keys.setRuntime()` 仅内存不落盘；stored key/OAuth refresh token 存本机 `agent.db`（SQLite）；models.yml 明文 key 是用户显式选择。
- auth-broker 模式：refresh token 集中托管于 broker，不出现在客户端（`auth.broker.url/token` + bearer allow-list）。
- MCP OAuth：Google issuer 请求 `access_type=offline` 保证 refresh token（18.2.9）；token 轮换保留 refresh endpoint 与 client metadata。
- 剪贴板/粘贴图片落 session artifact 目录（本地）。

## 6. Debug 与日志纪律

- Debug 输出不带大载荷：遥测默认不捕获 GenAI 内容（`OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT` 显式开启才有）；`printableEvent`（json 模式）丢弃大快照防体积平方膨胀。
- 崩溃路径：postmortem（pi-utils）`fatal()` 兜底；`omp-crash.log`；`session_exit` 诊断条目记录 dispose reason。
- `omp debug`（report-bundle 收集环境信息包）+ `omp grievances`（工具问题上报 auto-QA：`dev.autoqa`、autoqa.db、`PI_AUTO_QA_PUSH`）。

## 7. 遥测导出（`telemetry-export.ts` + `telemetry-export-otlp.ts`）

- OpenTelemetry SDK 全套：sdk-trace-base/node、sdk-metrics、sdk-logs、context-async-hooks、otlp-proto exporters（trace/metrics/logs）。
- env 全表：`OTEL_EXPORTER_OTLP_ENDPOINT/PROTOCOL`、`OTEL_EXPORTER_OTLP_TRACES/METRICS/LOGS_ENDPOINT/PROTOCOL`、`OTEL_TRACES/METRICS/LOGS_EXPORTER`、`OTEL_SDK_DISABLED`、`OTEL_LOG_LEVEL`、`OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT`。
- SDK 侧：`telemetry: AgentTelemetryConfig` 选项（`{}` 即启用 GenAI 语义约定 spans；hooks、content capture、cost estimator、agent identity；未注册 OTEL SDK 时 no-op tracer 安全）。
- install-id：跨 profile 共享安装 UUID（telemetry/grievance 去重）。

## 8. 用量与统计（`omp usage` / `omp stats` / omp-stats 包）

- `stats.db`（SQLite）本地统计；`omp stats`（HTTP dashboard :3847 / --json / --summary）；activity worker 与 sync worker（隐藏 worker 选择器）。
- `omp usage`：每 provider 已认证账号用量限额——20 个内置 usage fetcher（claude、openai-codex、gemini-cli、antigravity、kimi、minimax-code、muse-code、zai、github-copilot、cursor、synthetic、xai-oauth、devin、charm-hyper、ollama、ollama-cloud、cline-pass、umans、opencode-go、alibaba-token-plan）；`--history/--days(7)/--redact/-p provider`；daybreak badge；`/usage`、`/usage reset`。
- resets 赎回：`codexResets/claudeResets`（autoRedeem、minBlockedMinutes、keepCredits、salvageHorizonHours）；进程级共享 CodexAutoRedeemCoordinator 防并发会话双花（SDK 可注入替换，测试用）。
- native judgment usage 上报（含 error stop reasons 与 intent，18.3.0）。
