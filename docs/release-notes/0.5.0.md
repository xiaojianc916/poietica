# Poietica 0.5.0

这是架构重构（P0–P8）之后的第一个版本。与 0.4.4 相比，安装包内的一切都换了新骨架：
三个进程（UI / Host / Core）、三个微内核、20 个平台包 + 15 个功能包，Agent 引擎改为
随包发布的 Oh My Pi（omp）18.5.0，与你自己电脑上的全局 omp 完全隔离。

## 需要你知道的两件事

1. **历史对话与设置不从 0.4.x 迁移。** 0.5.0 使用全新的数据布局
   （`%APPDATA%\Poietica\`），旧版本的对话、设置与 API key **不会**被读取。
   装完之后请在设置里重新填一次 API key。
2. **安装包没有代码签名。** Windows SmartScreen 会提示「未知发布者」——
   点「更多信息」→「仍要运行」即可。以后取得证书会补上签名，流程不变。

## 这一版有什么

- 对话主线：线程列表、时间线、输入框（模型 / 思考档位 / 批准方式）、插话与排队、
  计划与目标模式、审批与提问、分支、导出、归档。
- 设置：通用、外观、快捷键、模型（API key / 自定义服务商 / 模型可见性）、
  Agent 设置、记忆与个性化、电脑操控与浏览器控制、技能 / 插件 / MCP、
  定时任务、审查（git）、终端、内置浏览器、用量、存储、关于。
- 本地能力：内置 Python 运行时（按需安装）、内置终端、内置浏览器
  （agent 可经 relay 操控）、自动更新。

## 已知限制

- 只有 Windows x64。
- 界面文案目前只有中文。
- 卸载会保留数据根（对话、设置、API key），重新安装后仍在。
